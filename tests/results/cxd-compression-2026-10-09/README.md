## Implementation and limits

Only the native ChatGPT handler's cloned upgrader enables compression. Upstream dialing enables it only for parsed exact `/backend-api/codex/responses`; other WS paths and fallback without offer retain their existing behavior. Each hop negotiates independently; do not copy another hop's extension response. Existing fasthttp/websocket supports no-context-takeover only, so the legal extension parameters still differ from the recorded official bare extension. A byte-identical string requires a different compatible context-takeover implementation; spoofing the header would corrupt frames. Final Rust already uses the official fork's DeflateConfig; internal Bifrost's offer is not proof of final OpenAI behavior.
